의사결정나무 실습실

CSV를 불러와 컬럼마다 역할(타깃·입력·메타·제외)과 유형을 정하면, 브라우저에서 바로 의사결정나무(CART, 지니 불순도)를 학습해 탐색 → 나무 → 판정 기준 → 새 데이터 예측까지 보여 줍니다. 타깃은 범주형(분류)이어야 합니다.

실습 데이터
내 CSV 파일
CSV 주소 (GitHub 링크도 가능)

컬럼 역할과 유형

Orange File 위젯의 역할 설정과 같습니다. 타깃은 하나만 고를 수 있습니다.

데이터 미리보기

타깃 분포

결측치

범주형 입력별 타깃 구성

막대 = 범주 안에서 각 타깃 등급의 비율. 막대 위 숫자는 건수입니다.

수치형 입력 분포 (타깃별)

학습 설정

결측은 학습 데이터 기준으로 채웁니다(수치 = 중앙값, 범주 = 최빈값). 범주형 입력은 ‘범주 = 값’ 이진 질문으로 나눕니다.

학습된 의사결정나무

나무 깊이 고르기

변수 중요도

시험 데이터 혼동행렬

행 = 실제, 열 = 예측. 대각선이 맞힌 건수입니다.

요약

잎 마디별 규칙

같은 변수의 조건은 구간 하나로 합쳐 표시했습니다. 비율은 학습 데이터 기준입니다.

새 데이터 입력

값을 바꾸면 바로 다시 예측합니다. 비워 두면 학습 때와 같은 값(중앙값·최빈값)으로 채웁니다.
